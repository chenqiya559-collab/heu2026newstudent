# 启航 HEU｜哈尔滨工程大学 2026 级新生入学指南

一个可直接部署的静态新生信息站，包含结构化指南、分类浏览、报到时间线、官方入口、反馈入口，以及基于本地知识库的检索式问答（轻量 RAG 演示）。

## 本地运行

```bash
npm install
npm run dev
```

如果电脑还没有安装 Node.js，也可以直接预览静态版：

```bash
python -m http.server 8080
```

然后访问 `http://localhost:8080`。

也可以使用快捷命令 `npm run serve` 启动同一个静态预览服务。

生产构建：

```bash
npm run build
```

构建结果在 `dist/`，可部署到 Vercel、Netlify 或 GitHub Pages。

## 数据维护

所有指南条目位于 `src/data.js`。每条信息包含：分类、摘要、正文、核验状态、来源、来源链接、更新时间与检索关键词。

正式参赛前建议：

1. 对照 2026 级录取通知书和各学院培养方案逐条核验。
2. 邀请不同学院同学试用，记录至少 10 份反馈并据此修改。
3. 将反馈弹窗接入真实问卷或后端。
4. 如需大模型 RAG，把当前 `retrieve()` 的检索结果作为上下文发送给模型；API 密钥必须放在服务端，不能写入前端。

## 信息边界

本站是学生整理项目，不是学校官方网站。可能变化的事项均标注了核验状态，最终以哈尔滨工程大学及各学院正式通知为准。

## 启航助手的 RAG 方案

当前问答不是简单的固定 FAQ，而是在浏览器中完成一套无需 API 密钥的本地 RAG 流程：

1. 将每篇指南拆分为摘要、正文要点和专题信息块。
2. 对问题进行中文短语切分，并扩展高数/数分、宿舍/公寓、Wi-Fi/校园网等同义表达。
3. 综合标题命中、完整短语、关键词和内容块重合度进行相关度排序。
4. 从不同知识条目中选择证据，生成带置信度、信息状态和引用入口的回答。
5. 命中 PPT、校园网等资源时，在回答中直接提供对应下载文件。
6. 无足够证据时拒绝猜测，并建议用户查看官方渠道。

用户提问会在当前浏览器本地进行匿名计数，为高频问题整理提供基础；GitHub Pages 是纯静态托管，暂时不会把统计上传到服务器。

## 后续迭代路线

1. 收集真实新生问题与试用反馈，扩充和修正知识库。
2. 增加课表工具、学院培养方案筛选和更细的校园位置检索。
3. 与学院教务、辅导员和校内服务部门建立信息核验流程。
4. 为每条政策增加责任人、有效期和复核记录，组建长期维护小组。
5. 接入有服务端密钥保护的大模型，在保留检索引用的前提下提升语言生成能力。
6. 接入经过用户同意的匿名问题统计后端，自动形成高频问题榜单。
7. 持续优化移动端、无障碍支持和低网速环境下的资源加载。

校园地图部分使用真实校园图作为底图，由 AI 辅助完成分类、关键词标注、检索入口和移动端呈现，避免生成式地图造成建筑位置失真。

## Vercel AI 配置

项目在 Vercel 部署后可通过 Serverless API 调用 DeepSeek。进入 Vercel 项目的 `Settings -> Environment Variables`，添加：

```text
AI_API_KEY=你的 API 密钥
AI_BASE_URL=https://api.deepseek.com
AI_MODEL=deepseek-chat
```

保存后重新部署。密钥只配置在 Vercel，不能写入前端代码或提交到 GitHub。未配置密钥、接口超时或继续使用 GitHub Pages 时，助手会自动使用本地知识库回答。

豆包方舟也可使用同一接口，将 `AI_BASE_URL` 改为 `https://ark.cn-beijing.volces.com/api/v3`，`AI_MODEL` 填写方舟控制台创建的推理接入点 ID，并使用对应的 `AI_API_KEY`。
